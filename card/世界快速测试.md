# 江南大学世界快速测试

在导航打开「多角色世界」并新建，分别向对应人物槽导入：

| 槽位 | 文件 |
| --- | --- |
| 苏祈雪 | suqixue/苏祈雪v2.json |
| 林晚 | linwan/林晚-江大测试.json |
| 卿 | qing/卿.json |

林晚旧卡保留。测试请选名称带「江大测试」的文件，不要选旧 林晚.json。

玩家另填自己的姓名与人设。开局建议选某年 **3 月**，例如 2026-03-10 17:00；地图选「江南大学南校区」。世界界面的林晚恋人绑定保持「卿」。两张新测试卡不依赖 {{user}} 来表示恋人，避免把玩家错认成卿。

已有世界也可以在「更新角色卡」分别替换林晚、卿。每次会保存为新世界副本，请在最新副本继续更新第二张卡。

可以用以下场景检查：

1. 私聊苏祈雪说「今晚和卿打球，下课不用等我」；再私聊卿说「今晚不打球了，要为祈雪准备生日惊喜，请保密」。在「知情来源」中，卿应能看到第二条，苏祈雪不能自动看到。
2. 创建四人群。若想明确测试苏祈雪暂时不看消息，先在「剧情时间与状态」设置她手机无法查看及结束时间，再发「哈喽」。卿与林晚可以回复或自然沉默；林晚只有读到卿的回复后才能接他的话。
3. 进入世界剧情，选林晚为本轮在场人物，输入「我请林晚帮忙保密生日礼物」。她可以选择保密、询问或告知；不能因为和祈雪关系好就固定泄密。实际告知并被接收后，祈雪才取得转述信息。

两张新卡是用于检查世界流程的校园测试版。林晚22岁、卿20岁，以及部分爱好和日常细节属于测试补全；例句和上述场景都未预置成已经发生的记忆。
