# 2026-11-09

## 角色卡阅读器（card/viewer.html）

背景：`card/` 下的卡是 Tavern v2 格式（`data.personality` 3~4 千字 + `character_book.entries` 17 条、每条 500~2600 字），直接看 JSON 没法读。

新增：
- `card/viewer.html` — 零依赖单文件阅读器。左侧结构目录（概览/人物设定按【】分节/开场白/世界书/地理/原始 JSON），正文渲染 `【小节】`、多级 `-` 列表、`1.` 编号、`**粗体**`、`{{user}}`；含「禁止/不得」的行标红。关键词 chip 带 `×N`（全文出现次数），点击即搜。搜索 `/` 聚焦、实时高亮并自动展开命中词条。世界书可按 常驻/触发/停用 过滤。
- 内联编辑：人物小节（可改【标题】+正文）、开场白、词条（标题+关键词+正文）就地改，写内存后顶栏显示「N 处修改」；`Ctrl+S` 导出 `原名.edited.json`（在原始 JSON 上就地改字段，其余键原样保留），另有 Markdown 通读稿导出、放弃修改。
- `card/build-preview.cjs` — 扫 `card/**/*.json`，按 `data.name` + `personality`/`character_book` 判卡，按 mtime 倒序（正在改的排最前），内联进 viewer 生成 `preview.html` + `manifest.json`；`--list` 只打印清单。
- `card/view.cmd` — 双击 = build + 打开 preview.html。
- `window.__CARD_API__.{json,md,state}()` 暴露导出结果供断言（页面的 `S` 是闭包，测试拿不到）。

坑：
- 无头 Edge 点 blob 下载会让 playwright 内部留下未处理 rejection 把进程带崩 → `process.on('unhandledRejection', ()=>{})` 抑制；要在点击前注册 `page.on('download')` 才能拿到文件名。
- `preview.html` 内联了卡正文，而 `/card/suqixue/` 本来就在 gitignore 里（内容敏感），所以 preview.html / manifest.json 必须一起 ignore。

验证：`node tools/refactor/shot-card-viewer.cjs [--headful]`，21/21（含导出 JSON 字段回写、Markdown 结构、还原、切卡）。
文档：`docs/card-viewer.md`。
