# 2026-10-19

## 聊天模型选择改造（快捷面板 → 输入框左侧下拉）

需求：快捷面板里固定 3 个「槽位」只能快捷预选 3 个模型，改模型要逐个配槽位，太麻烦。
改为：输入框工具栏右下（齿轮左侧）加一个模型下拉，直接列 `availableModels`（接口 `/models` 拉取），带搜索 + 模型家族分类，点一下即切换。

改动落点：
- `index.html`：删掉 `#chat-quick-panel` 里的 `.chat-model-slots` 三槽位区块；右侧控制区新增 `.chat-model-menu-container`
  （`#chat-model-menu` 面板：搜索框 / 分类 chips 复用 `modelTags` / 列表复用 `chatModelMenuModels`），齿轮按钮点击顺带关闭模型菜单。
- `01-state-app-shell.js`：新增 `showChatModelMenu` / `chatModelMenuQuery` / `chatModelMenuTag`。
- `02-state-settings.js`：新增 `chatModelMenuModels`（按 query + tag 过滤 `availableModels`）、`toggleChatModelMenu`、
  `closeChatModelMenu`、`selectChatModel`（直接写 `settings.model`，由既有 watch 同步 `qualityModel` 与 `currentModelMode`）；
  删除只服务旧槽位 UI 的 `modelMode` computed 与 `selectChatModelSlot`。
  保留 `chatModelSlots` / `qualityModel|balancedModel|fastModel` —— 设置页槽位选择器与 `character/index.html` 的「自定义模型」仍读它们。
- `23-lifecycle.js`：全局点击外部收起 `.chat-model-menu-container`。
- `assets/css/styles.css`：删除失效的 `.chat-model-slots > .segmented-switch__indicator`。
- `app.js`：return 里加下拉相关导出（含 `availableModels`），移除 `modelMode` / `chatModelSlots` / `selectChatModelSlot`。

验证：新增 `tools/refactor/smoke-chat-model-menu.cjs`（playwright-core + 系统 Edge，16 项，全过；含搜索/分类/切换/点击外部关闭/移动端不出屏）。
注意：该环境下 CDN 偶发拉不到 marked，冒烟脚本需在 addInitScript 里兜底 `marked`/`DOMPurify`，否则 app 启动即中断。
