## 微信单条消息编辑 / 删除（新增）

目标：让微信气泡像 RP 消息一样可编辑、拷贝、删除；改动同时作用于气泡、下一轮请求、RP 回灌摘要。

- `25-wechat.js`：新增 `wechatEditingId` / `wechatEditDraft` / `wechatMenu` 状态，及
  `findWechatMessage`、`canEditWechatMessage`、`openWechatMessageMenu`（按按钮 rect 固定定位并夹视口）、
  `startWechatEdit`（自动聚焦 + 落光标）、`autoResizeWechatEdit`、`saveWechatEdit`、`cancelWechatEdit`、
  `copyWechatMessageText`、`deleteWechatMessage`（confirmAction 二次确认）。
  生成中（isWechatGenerating）拒绝改删；`openWechat` / `closeWechat` / `clearWechatTimeline` 复位编辑态与菜单。
- 语义决定：编辑用户消息时删除 `replyDecision` / `replySilence`（原空回结论失效，重新计未回复），但不自动请求回复；
  删除后不回收图片资源；编辑不重写前情提要摘要（与 RP 编辑一致）。被编辑消息写入 `editedAt`。
- `26-recap.js`：`adjustRecapWechatCoverageAfterDelete(indexInWechat)` —— coversWechatCount 是前缀计数，
  删到覆盖段内要减一并落盘。

  气泡内编辑块；固定定位 `.wx-msg-menu` + 透明遮罩（z 56/57，压在 .wx-root 55 上、抽屉 58 下）。
- `wechat.css`：`.wx-tools` / `.wx-tool-btn`（hover 变实、触屏常显 0.8）/ `.wx-msg-menu*` / `.wx-edit*`。
