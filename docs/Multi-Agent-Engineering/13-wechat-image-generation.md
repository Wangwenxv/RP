# 世界微信按需生图

日期：2026-11-13。

世界微信已从只支持文字扩展到按角色模型提示词生成图片：支持私聊、群聊与 RP 原生 `tool_wechat.image`。用户在“设置 → 微信生图”填写自己的 Key，默认使用已实测的 STA1N `nai-diffusion-4-5-full:k_dpmpp_2m`，可选择模型、协议与比例。

例：角色说正在吃黄焖鸡，玩家要求拍照，模型给出饭菜画面提示词，程序取图并落盘后发出图片气泡。生成是一次角色决策中的有界动作，不是每轮自动插图。发件人、会话成员、阅读来源、世界分支与玩家回应点继续使用原规则。

新增 `turn.preparedActor` 保存待发送的角色提案与图片 ID，`world_media_*` 单独保存像素。失败后“继续未完成回合”沿用提案与已保存资源；生图成功而消息提交失败不重复付费调用。世界包包含资源表，导入会重新分配图片 ID。图片不能通过文字记录编辑替换，需回退后重新发送；历史分支的图片仍保留以便恢复。

完整设置、协议、存储、限制、入口与验证见 [微信生图交接](../wechat-image-generation.md)，实际请求格式和早期踩坑见 [STA1N 经验](../sta1n-image-generation.md)。此前 06/11 中“世界微信只支持文本”的结论已被本次图片能力部分替代；世界端玩家上传、相册、识图、语音和文件仍属于后续媒体工作。
