# 地点可视化目录交接（2026-11-06）

玩家难以直接阅读地图JSON，需要看清整个校园有哪些地点，以及每个地点的介绍。本次提供项目内只读浏览与完整文字目录，并在会话中提供可点选的地图。

## 玩家入口

导航菜单 → **地图与地理环境** → 江大地图 → **浏览地点**。

左侧是原地图与现有标点；右侧有搜索、片区筛选、全部地点目录和完整介绍。可点击图上标记或地点名称进行切换，可使用1×/2×/3×缩放。同坐标的图书馆各楼层等地点可从目录分别选取，再次点击同一图上标记也会轮流切换。

默认显示54个场景地点，可勾选“显示路网节点”查看另外17个节点，共71个地点；道路显示独立勾选，当前路网75条边。浏览页适用于所有共享地图，读取地图管理中当前记录，包括本地修改及导入地图。

浏览不会修改地图、角色绑定或聊天位置，也不会调用模型。

## 介绍如何展示

- 名称与别名、用途/功能、独立地点介绍，全部按当前地图数据展示，不调用 `briefPlace` 或截取180字。
- 开放时间、关闭时间、查寝、进入限制和开放时段等规则单独展示。
- 所属片区完整背景可展开，注明数据中的来源；共享文化另有展开项。
- 没有独立介绍的地点明确提示未填写；路网节点只用于道路连接，不生成虚构建筑介绍。
- 地点的独立介绍与共享片区背景分开显示，避免把某座楼专有设施误看成整个片区每栋建筑都有。
- 来源文本按文字显示，输入中的HTML没有执行权限。

**本轮没有改动地图里的地点介绍、片区归属、原图或路网。** 部分路网节点的片区仍是原数据中粗略的academic分类，浏览页如实显示；它们不是日常场景地点。

## 完整文字目录

[江大南校区 · 当前地点与完整介绍](./jiangnan-campus-catalog.md) 列出全部54个场景地点、各地点完整介绍/开放规则、5个片区完整背景及17个路网节点。分区计数：教学区22、生活区21、图书馆区3、体育区7、校外贝岗1。

文字目录是工程 `worlds/jiangnan-south-campus.json` 的生成快照，不读取玩家浏览器IndexedDB中的个别修改；查看那些修改用项目内浏览页。源JSON改变后重新生成目录即可。

## 代码与生成

| 文件 | 职责 |
| --- | --- |
| `assets/js/map-atlas.js` | Vue只读浏览：完整地点/片区详情、目录、搜索、筛选、地图点选、同坐标地点切换 |
| `assets/js/map-components.js` | 地图列表增加“浏览地点”入口与返回列表 |
| `assets/css/maps.css` | 地点目录、图上选择环、暗色适配 |
| `index.html` | 加载地图浏览组件，位于map-components之前 |
| `tools/geography/campus-atlas-fragment.html` | 会话地图的可复用模板，只展示现有原图、地点与背景 |
| `tools/geography/build-campus-atlas.py` | 从当前源JSON生成文字目录与会话地图；会话预览图缩小以控制文件体积，不改原图/地图包 |
| `docs/jiangnan-campus-catalog.md` | 完整可读目录 |

会话地图的当前预览约300KB，含全部71个地点和5个片区完整介绍。原图仅为预览缩小；项目与导出地图包继续保留原图。

重新生成示例（output为会话预览保存目录）：

```powershell
python tools/geography/build-campus-atlas.py --output "目标目录/jiangnan-campus-atlas.html"
```
