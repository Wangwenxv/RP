# 地图管理与便携地图包交接（2026-11-06）

本次在江大地理引擎和组合工具之上，补上玩家操作入口。工程为 `D:\aiops_wwx\test\RP-Hub`，保持原有界面风格。本项目不属于CWUI。

## 玩家从哪里设置

- 导航菜单 → **地图与地理环境**；世界书页顶栏也有同名入口。
- 角色卡管理 → 编辑角色 → **地理环境**，选择共享地图并设置玩家、角色各自住址。住址不会初始化当前位置。
- 角色编辑中的“打开地图管理”暂时收起编辑页，地图页的“返回角色编辑”可继续原草稿。
- 地图编辑草稿在本次页面内导航时保留；**保存地图**后才写入数据库，刷新前仍须保存。

世界书负责简短的世界说明和触发条件；地图管理负责原图、标注和路网；`tool_geo`负责只读查询、距离与行动成本。同一地图可以绑定多个角色，RP和微信都用同一份共享世界。人物独有的地点经历仍在角色 `geography.placeMemories` 中。

江大试点已内置，正常玩家无需编辑源码、运行脚本或上传D盘路径。内置13栋沿已标注道路至实验楼A区按用户确认的正常步行约35分钟标定；其他路线仍为估算。

## 导入、导出与分享

地图列表上的 **导出地图包** 生成一个 `.rpmap.json` 文件：

```json
{
  "format": "rp-hub-map",
  "version": 1,
  "world": { "version": 1, "id": "my-map", "name": "世界名称", "imageSize": [1000, 1000], "places": [], "edges": [] },
  "image": { "dataUrl": "data:image/jpeg;base64,原图片字节" }
}
```

包中包含原图字节、地点坐标/名称/别名/用途/局部环境/开放规则、道路端点/折线/长度/交通规则、片区文化、距离标定。原图没有经过缩放或重编码；`imageSize`表示**标注坐标尺寸**，可与原图的实际像素尺寸不同。导入、保存时验证结构和图片格式/解码，拒绝不合法资料。

接收方在地图列表点 **导入地图包** 即可使用；不需要发送者的文件目录或联网下载底图。

- 与现有地图ID冲突时生成导入副本并提示；不自动覆盖旧图或改现有角色绑定。需要使用副本时在角色编辑中重新选它。
- 内置地图可以保存本地修改，也可另存副本；不能直接删除内置版本。删除本地修改会恢复内置版本。
- 被启用地理功能的角色引用的地图不能删除，先解除相关角色绑定。
- **角色卡JSON/PNG只携带地图绑定及角色私人地点经历**，不重复塞入整张共享地图和原图。分享自建世界时同时分享地图包，接收方先导入地图包再导入角色卡；缺失地图会在角色地理环境页提示。
- 支持PNG/JPEG/WebP，原图上限12MB，地图包上限20MB，结构资料上限2MB。仍有原地理引擎2000地点/10000道路容量限制。
- SVG、远程图片URL和仅本地图片路径不作为可便携原图接受。

## 换一张图如何建立地图

1. 新建地图，上传底图，填写地图名称。单独图片不会自动识别建筑/道路/文化，也不会自动得到现实比例尺。
2. 添加地点，填写名称、别名、用途、环境和开放限制；点 **在图上定位** 后点击底图，或输入坐标。需要精细标注时使用2×/3×缩放。
3. 添加道路，选择两端地点；按实际可走通道点击增加折点。设置步行/骑行、单向/封闭、是否需要下车推行。可添加路网节点连接路口、桥、隧道，避开湖泊和障碍。
4. 在 **文化 / 标定** 填共享背景，选择一种距离依据：
   - 知道一条连通路线的正常步行分钟：选择起终点、时间和假定步速；保存/检查时重新标定最短可走路线。不能与道路米数混用。
   - 有可靠比例尺：填写每坐标单位多少米；有实测道路可逐条填米数并标明实测。
   - 都不知道：保留未标定，工具返回时间未知；不填一个随意比例制造确定距离。所有边都有明确米数时无需整图比例。
5. 使用两点路程检查，核对道路和步行/骑车成本，再保存并绑定角色。

高级结构编辑可修改 `districts` 片区长背景、坐标尺寸、开放时段及标定来源等。应用时先校验。没有自动识图模型调用，玩家录入和路线计算没有模型费用。

更换底图会保留已有标注坐标尺寸，防止简单替换图片导致坐标漂移；如果新图的布局改变，应新建地图或重新标注。更换角色绑定的世界时建议使用新剧情分支，并用“我在…”或 `/geo` 重新明确位置。同名地点的历史不能保证仍有新地图中的语义。

## 费用、上下文和位置规则

`tool_geo context` 一次提供地点用途/局部环境、双方位置及步行/骑车成本；多个独立查询可用 `batch`，RP/微信也支持同响应多个业务调用。明确地理问题的短资料可由本地预取提供，无需额外识图模型。

**图片与整张地图不进入RP/微信提示词、聊天气泡或记忆。** 运行时工具只看到共享地图中的结构数据，按需返回有限的地点/路线结果。仍有工具schema、短规则、位置证据及本轮必要结果的token成本，不承诺零上下文或所有模型完全避免瞬移。

当前位置继续从当前剧情分支证据重放：住址不是当前位置；“我要去”不是到达；含糊实验楼、计划、离开或时间跳跃按既有规则处理。地图不给角色强制意愿，愿不愿来由人物内核决定。导入的描述和背景只是世界资料，其中的命令没有工具操作权限。
