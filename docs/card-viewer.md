# 角色卡阅读器（card/viewer.html）

把 `card/` 下的角色卡 JSON 渲染成可读页面：长文本按【】分节排版、世界书词条带关键词与注入方式、支持全文搜索、**可在页面里直接改并导出回 JSON**。

## 怎么打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 一键（推荐） | 双击 `card/view.cmd` | 扫描 `card/` 下全部角色卡 → 生成 `preview.html`（数据内联）→ 自动打开 |
| 拖拽 | 双击 `card/viewer.html`，把 JSON 拖进窗口 | 适合临时看单个文件，可一次拖多张 |
| 只列清单 | `node card/build-preview.cjs --list` | 不动文件，只打印识别到哪些卡 |

`preview.html` 是生成物（内联了卡片正文），已加入 `.gitignore`；改了卡重新跑一次 `view.cmd` 即可刷新。

## 页面里能做什么

- **结构目录**：左侧按「概览 / 人物设定（逐小节）/ 开场白 / 世界书（逐词条）/ 地理绑定 / 原始 JSON」分组，滚动时自动高亮。
- **正文渲染**：识别 `【小节】`、`- 列表`（按缩进分级）、`1. 编号`、`**加粗**`、`{{user}}`；含「禁止 / 不得」的行会标红，方便查边界条款。
- **关键词计数**：每个词条的关键词后面标 `×N`，是该词在「人物设定 + 开场白 + 全部词条」中的出现次数，用来判断触发词是否真的用得上。点一下即可把它当搜索词。
- **搜索**：`/` 聚焦，实时统计命中数并高亮，命中处会自动展开折叠的词条。
- **筛选**：世界书区域可按 全部 / 常驻 / 触发 / 停用 过滤。
- **字号**：A− / A＋，记在 localStorage。

## 边看边改

每段（人物小节 / 开场白 / 词条）右上角悬浮出现「编辑 / 复制」。

- **人物小节**：可改小节标题（即【】里的内容）+ 正文
- **词条**：可改词条标题、关键词（逗号/顿号分隔）、正文
- 保存只写内存，顶栏出现「N 处修改」。`Ctrl+S` 或「导出 → JSON」拿到 `原名.edited.json`，**替换原卡即可**。
- 「导出 → Markdown」把整卡拍平成一份通读稿（`# 名字 / ## 人物设定 / ## 世界书`），适合丢给 AI 或做 diff。
- 「放弃全部修改」回到载入时的状态。

导出的 JSON 是在原始 JSON 结构上就地改字段，`data` 以外的键、未编辑的字段（含 `extensions`、`character_book` 的其余属性）原样保留，文件仍是合法 v2 卡。

## 实现要点

- `viewer.html`：零依赖单文件，`window.__CARDS__` 存在则用内联数据，否则 `fetch('manifest.json')`，再不行落到拖拽/选文件。
- `build-preview.cjs`：扫 `card/**/*.json`，按 `data.name` + `personality`/`character_book` 判定是否为角色卡，按文件修改时间倒序（最近在改的排最前），把数据注入 `viewer.html` 的 `</head>` 前生成 `preview.html`。
- 编辑回写：人物设定按小节行号 `splice` 回原文本，词条直接改 `entries[i]` 对应字段。
- `window.__CARD_API__.{json,md,state}()` 暴露导出结果，供自动化断言。
